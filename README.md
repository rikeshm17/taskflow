# ⚡ TaskFlow

A modern task management web application built using React, TypeScript, and Supabase.

## ✨ Features

- 🔐 User Authentication
- ✅ Create, Edit, Delete Tasks
- 📅 Due Dates
- 🔍 Search & Filter
- 📊 Dashboard Statistics
- 📈 Progress Tracking
- 🌙 Modern UI
- ☁️ Supabase Backend
- 🚀 Responsive Design

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Supabase
- React Router
- CSS
